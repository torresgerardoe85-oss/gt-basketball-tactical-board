# GT Basketball Tactical Board

Pizarra táctica independiente para entrenadores de baloncesto.

Funciones: solo marcador o con fichas; dibujo y movimiento simultáneo; bloquear dibujo; cinco colores; media cancha o completa; borrador; deshacer/rehacer; guardado local; PWA offline.

Pendiente: verificar en dispositivos reales y publicar en HTTPS. No modifica CourtPlay ni HoopMetrics.
